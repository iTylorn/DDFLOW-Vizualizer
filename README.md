# FlowVizualizer для DD FLOW

Редактор карт переделов для Windows с файловым обменом с 1С ERP. В приложении можно расставить переделы, назначить группы, построить связи и настроить РКТ, макеты запуска и склады.

## Скачать и запустить

1. Скачайте `FlowVisualizer_Windows_v26.zip` на странице [Releases](https://github.com/iTylorn/DDFLOW-Vizualizer/releases/latest).
2. Распакуйте архив целиком и запустите `FlowVisualizer_v26/FlowVisualizer_v26.exe`. Служебная папка `_internal` лежит рядом с EXE.
3. Для первого знакомства откройте через «Выгрузка 1С…» учебный файл `Демо_не_данные_1С.xlsx`. Для обмена с вашей базой используется `FlowExport.epf` из архива.

Для запуска скачанной сборки Windows x64 нужны Windows 10 или 11. Если Windows сообщает об отсутствии `VCRUNTIME140.dll` или `MSVCP140.dll`, установите [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe). Инструкция по выгрузке и загрузке находится в [ОБМЕН_С_1С.md](ОБМЕН_С_1С.md).

## Работа с картой

- Сохраните редактируемую карту как `.flow.json`. Проект хранит оба вида расположения и слой оформления.
- Кнопка «Склады на схеме» показывает входные стеллажи и склады остатков в работе внутри карточек.
- Команда «Печать / PDF…» открывает предпросмотр на одном или нескольких листах A4.
- Для записи в 1С создайте отдельный файл командой «Выгрузить переделы в 1С…». В обработке сверьте сопоставление, проверьте предпросмотр и подтвердите запись.

## Исходники и вклад

Приложение находится в `flow_visualizer/`, исходники внешней обработки 1С — в [one_c/](one_c/). Для предложений и исправлений можно создать форк и открыть pull request. Для воспроизведения ошибок используйте вымышленные карты и склады.

Запуск и проверка из корня репозитория в PowerShell с Python 3.10:

```powershell
python -m pip install -r requirements.txt
python -m flow_visualizer.gui
python -m unittest discover -s tests
```

Сборка автономного приложения:

```powershell
& ./flow_visualizer/build_windows.ps1 -AppName FlowVisualizer_v26
```

Для создания учебного XLSX запустите `python -m flow_visualizer.create_demo`.
